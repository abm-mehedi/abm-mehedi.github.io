## 🌐 কীভাবে এটি সম্পূর্ণ ফ্রি অনলাইনে হোস্ট করবেন (Hosting Options)

আপনার পোর্টফোলিও লিঙ্কডইনে যোগ করার জন্য এটিকে অনলাইনে লাইভ করা সবচেয়ে ভালো। নিচে দুটি সবচেয়ে সহজ এবং সম্পূর্ণ ফ্রি উপায় দেওয়া হলো:

### অপশন ১: Netlify Drop (সবচেয়ে সহজ - মাত্র ১ মিনিট)
১. [Netlify Drop](https://app.netlify.com/drop) ওয়েবসাইটে যান।
২. আপনার `mehedi-portfolio` ফোল্ডারটি মাউস দিয়ে ড্র্যাগ করে ছেড়ে দিন (Drag & Drop)।
৩. সাথে সাথে এটি লাইভ হয়ে যাবে এবং একটি ফ্রি লিঙ্ক (যেমন: `mehedihasan.netlify.app`) পেয়ে যাবেন!

### অপশন ২: GitHub Pages (প্রফেশনাল ও পার্মানেন্ট)
১. GitHub.com-এ একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `mehedi-portfolio`)।
২. এই ফোল্ডারের ফাইলগুলো সেখানে আপলোড করুন।
৩. Settings > Pages এ গিয়ে "Deploy from a branch (main)" সিলেক্ট করুন।
৪. আপনার ওয়েবসাইট লাইভ হয়ে যাবে: `https://yourusername.github.io/mehedi-portfolio/`

## 💼 LinkedIn প্রোফাইলে কীভাবে যুক্ত করবেন (How to Add to LinkedIn)

আপনার লিঙ্কডইন প্রোফাইলে এটি ৩টি মূল জায়গায় দিতে পারেন:

### ১. Profile Header "Custom button / Link" এ:
- আপনার LinkedIn প্রোফাইলে গিয়ে **Edit intro** (পেন্সিল আইকন ✏️) ক্লিক করুন।
- নিচের দিকে স্ক্রোল করে **Custom button** সেকশনে যান।
- **Link** নির্বাচন করুন এবং আপনার পোর্টফোলিও URL দিন।
- Button text দিন: **"View Portfolio"** অথবা **"Visit my website"**।

### ২. Featured Section (ফিচার্ড সেকশন) এ:
- প্রোফাইলের **Add profile section** > **Recommended** > **Add featured** এ যান।
- **+** আইকনে ক্লিক করে **Add a link** সিলেক্ট করুন।
- আপনার পোর্টফোলিও লিঙ্কটি পেস্ট করুন এবং Title হিসেবে দিন:
  `A.B.M Mehedi Hasan | Executive Portfolio & Career Dossier`
- Save করুন। আপনার ছবি সহ চমৎকার একটি প্রিভিউ কার্ড প্রোফাইলের মাঝখানে দেখা যাবে।

### ৩. Contact Info তে:
- প্রোফাইল হেডার থেকে **Contact info** > Edit ক্লিক করুন।
- **Website** অপশনে গিয়ে লিঙ্ক পেস্ট করুন এবং টাইপ দিন **Portfolio** বা **Personal**।
